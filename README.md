# Pol Vidal Miranda

Machine learning engineer based in Barcelona, with a background in electronic engineering and an MSc in Machine Learning and Cybersecurity from UPC (8.5/10). For my master's thesis, in collaboration with Amsterdam UMC, I built and evaluated models that predict relapse in patients with alcohol use disorder, with a strong focus on honest evaluation and explainable AI (SHAP, LIME, Integrated Gradients).

I'm detail-oriented by nature: I care about every step, from raw data to the final decision. What matters most to me in ML is models that hold up under careful evaluation, and results a non-technical person can understand and act on.

## Projects

- [football-metrics-analysis](https://github.com/PolVidal/football-metrics-analysis): football data platform built on DuckDB, merging StatsBomb, Wyscout, Transfermarkt and ESPN with cross-source player matching, my own xG and expected-threat (xT) models, a Streamlit app, and GitHub Actions pipelines that update the data daily and generate charts and 3D videos.
- [football_object_detection_yolov8](https://github.com/PolVidal/football_object_detection_yolov8): custom-trained YOLOv8 detecting the ball and referee in Bundesliga footage, from frame extraction and manual annotation to test-set evaluation.
- [CodePilot](https://github.com/Anass-23/CodePilot) (team project): local RAG assistant that answers questions about a Python codebase, using AST-based chunking, CodeBERT embeddings, FAISS search and CodeLlama via Ollama.
- [distributed_training_pytorch](https://github.com/PolVidal/distributed_training_pytorch): mini-batch vs DistributedDataParallel training compared on MNIST and CIFAR-10 (CNN and ResNet), with an analysis of when communication overhead outweighs the speed-up.
- **ML trading system** (private): point-in-time S&P 500 data pipeline, gradient-boosting stock ranking and a walk-forward backtest with trading costs, including a data audit that exposed fake returns from unadjusted stock splits.
